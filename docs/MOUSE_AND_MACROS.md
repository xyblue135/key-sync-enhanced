# 1.45：原生侧键、滚轮和点击宏

## 侧键和滚轮绑定单个位置

1. 启动游戏，从 KeySync 通知栏进入「编辑布局」。
2. 新建普通按钮或打开已有按钮的绑定窗口。
3. 按侧键／转动滚轮，或从「鼠标绑定」下拉列表选择：侧键1（后退）、侧键2（前进）、滚轮上／下／左／右。
4. 拖动普通按钮到目标位置，确认绑定并完成编辑。

侧键支持普通点击、按住等已有模式。滚轮没有物理按住状态，其普通位置绑定始终执行点击；旧轮盘处于打开状态时，滚轮仍控制轮盘。侧键在光标模式和射击模式都使用绑定位置。横向滚轮只在硬件与 Android 实际上报横向滚动时有效。

## 一个侧键依次点击多个位置

这里的步骤直接叫位置 1、2、3……，与 Tab、Esc 等普通键位无关。

1. 打开设置，在目标预设右侧菜单选择「点击宏（顺序点位）」。
2. 点击「新建宏」，输入名称，选择触发键，例如「侧键1（后退）」。也可以用滚轮方向或键盘键触发。
3. 添加所需位置；「上移」调整顺序，「删除位置」移除步骤。每个位置设置松开后到下一步的等待时间，范围 0–5000 毫秒。
4. 保存。新宏默认停用，先完成点位摆放。
5. 启动游戏，从通知栏进入「编辑布局」。底部选择需要编辑的宏，将编号 1、2、3……拖到各自目标位置。拖动结束及完成编辑都会保存。
6. 回到宏设置，打开「启用此宏」并保存，然后返回游戏。

例如，某操作需要点击两个按钮：将 1 放到第一个按钮、2 放到第二个按钮，先把步骤间隔设为 100–300ms，根据游戏界面反应时间调整。触发后只执行一遍，不连发。

## 执行规则

- 第一步立即按下，每个点击保持 50ms 再松开；最后一步结束后立即完成，不等待最后一项的间隔。
- 宏优先于同一触发键的普通位置绑定和交换对；同一个键只能启用一个宏。
- 同时只运行一个宏；运行期间的新宏触发会被忽略，不中断当前宏、不累积队列。物理长按或键盘重复事件不会自动重跑。
- 失焦、打开通知栏进入编辑、旋转引发映射重建、切换预设和关闭服务会取消剩余步骤并释放宏触点。再次运行需要重新触发。
- 宏点只在编辑模式显示。它们独立于普通按键显隐，普通游戏模式不会显示宏编号。
- 点位跟随当前悬浮视口尺寸按比例换算；不同游戏界面布局仍需自己校准。
- 宏随预设保存／复制／导入导出。旧预设无需迁移；G502 的 DPI、狙击键和其他特殊按钮此次未做专用适配。

## 自动检查

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest --offline --console=plain
```

JVM 回归覆盖侧键双重上报去重、混合按键释放、键盘 Back 与鼠标侧键区分、滚轮四向／小数累计、宏顺序与间隔、取消后的旧回调、重复触发、配置兼容及导入校验。

`MacroPointsDragTest` 检查拖动期间替换 Profile 状态后，编号点能继续移动并保存；需要设备或模拟器执行。

## 真机验收

1. 左键按住时反复按侧键，确认侧键只触发一次，左键不会被误松开；侧键不能导致系统返回。
2. 将四个滚轮方向分别绑定位置，检查方向正确；轮盘打开时不额外触发普通位置或宏。
3. 宏设 1 → 2 → 3，分别设 0ms、500ms 的间隔，检查执行顺序和只运行一遍。
4. 宏执行中拉下通知栏、进入编辑、切换预设或关闭服务，确认剩余步骤不再发生；重新启动宏不受旧回调影响。
5. 拖动宏点后关闭再启动、复制预设、导出再导入，确认点位、顺序、间隔和开关保留。
6. 持续按住侧键及快速重复按侧键，确认不会在松开后继续排队执行。

本地构建和 JVM 测试不能代替设备的 USB／蓝牙事件与真实游戏触摸验收。
